# Clinix

Cloud-native clinic ERP for aesthetic and medical clinics, built for a global market.

| Repo | Role |
|---|---|
| [clinix](https://github.com/clinix-erp/clinix) | Core ERP: .NET 10 Aspire modular monolith (Tenancy, Clients, Scheduling, Sales, Fiscal, Accounting, Inventory, Catalog) and web UIs |
| [clinix-mobile](https://github.com/clinix-erp/clinix-mobile) | MAUI Blazor Hybrid staff app; consumes Clinix.UI.Kit and Clinix.Contracts packages |
| [clinix-data](https://github.com/clinix-erp/clinix-data) | openFDA and Israel MoH (data.gov.il) pipelines into a global product catalog |
| [clinix-afterarc](https://github.com/clinix-erp/clinix-afterarc) | Isolated post-treatment tracking and consented outcome registry |
| [clinix-infra](https://github.com/clinix-erp/clinix-infra) | IaC and deployment (Azure / AWS, undecided) |
| [clinix-security](https://github.com/clinix-erp/clinix-security) | Threat model, policies and security docs |
| [clinix-pulse](https://github.com/clinix-erp/clinix-pulse) | Live stakeholder progress dashboard |
| [clinix-ops](https://github.com/clinix-erp/clinix-ops) | Company operations: registration, domains, accounts, stakeholders |

Roadmap: [Clinix Roadmap](https://github.com/orgs/clinix-erp/projects/1) · Ops: [Clinix Ops](https://github.com/orgs/clinix-erp/projects/2)
