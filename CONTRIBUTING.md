# Contributing to Clinix

- Branch from `main`; name branches `feat/…`, `fix/…`, `chore/…`.
- Use Conventional Commits (`feat:`, `fix:`, `docs:` …).
- Every PR links an issue on the [Clinix Roadmap](https://github.com/orgs/clinix-erp/projects/1).
- Respect each repo's dependency rule (see its README). Cross-repo use goes through published packages/contracts only.
- CI must be green and at least one review is required before merge.
- Never commit secrets or patient data.
